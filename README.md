# how-to-win-the-premier-league
Reconstructing football analytics models from first principles, inspired by Ian Graham's How to Win the Premier League.

The goal is to understand not only how these models work, but why
particular modelling choices are made and how they can be evaluated
using real football data.

## Models
| Model | Status | Description |
|------|------|-------------|
| Expected Goals (xG) | 🚧 In progress | Probability that a shot results in a goal |
| Possession Value | ⬜ Planned | Value of changes in possession |
| ... | | |

## Philosophy
For each model I aim to:

1. Understand the methodology
2. Identify suitable football data
3. Reconstruct the model independently
4. Evaluate its predictive performance
5. Compare alternative modelling choices
6. Visualize the results
7. Document limitations and assumptions
