# Data

The expected goals project uses **StatsBomb Open Data**.

The raw data is not committed to this repository in order to keep the repository lightweight and avoid duplicating externally maintained datasets.

## Source

StatsBomb Open Data:
https://github.com/statsbomb/open-data

## Usage

Download the StatsBomb Open Data repository and place the required files inside the appropriate `data/raw/` directory.

Processed datasets created during the modelling workflow can be stored in:

```text
data/processed/
```

The notebooks document any filtering, feature engineering, and preprocessing steps used before modelling.
